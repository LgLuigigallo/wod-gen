          Per modelli Codex usa il provider "OpenAI — Responses" con una chiave API OpenAI. Un login ChatGPT/Codex CLI non può essere usato direttamente da una web-app.
        

      


      
      

        
        

          
          
        

        

          La chiave è salvata su questo telefono. Usa una chiave con limite di spesa e non condividere il telefono sbloccato.
        

      


      
      

        
        

          
          
        

        

          Modello attivo:
          
        

        

          Scegli un modello dal menu a tendina o tocca "Carica modelli" per scaricare la lista ufficiale dalla tua chiave API. Puoi anche digitare un nome a mano.
        

      


      
      

        
        
        

          URL di base dell'endpoint compatibile OpenAI o di un proxy CORS.
        

      


      
      

        
        

          Se disattivato, la chiave rimarrà valida solo per la sessione corrente del browser.
